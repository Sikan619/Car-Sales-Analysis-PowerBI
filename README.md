# 🚗 Car Sales Analysis Dashboard | Power BI

## Project Overview

An interactive Power BI dashboard designed to analyze car sales performance, revenue, profitability, customer purchasing patterns, and business trends.

## 🎯 Business Objectives

- Monitor overall sales performance.
- Analyze revenue and profit trends.
- Identify top-performing car brands and cities.
- Understand customer payment preferences.
- Evaluate discount distribution.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Visualization
- Data Analytics

## 📊 Key Performance Indicators

- Total Sales
- Total Profit
- Units Sold
- Average Selling Price
- Discount Analysis

## 📈 Dashboard Features

- Brand-wise sales analysis
- City-wise sales performance
- Payment mode distribution
- Monthly sales trends
- Profitability analysis
- Interactive filters and slicers

## 🚀 How to Run

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `CAR-SALES-REPORT.pbix`.
4. Refresh the data if the original dataset is available.
5. Explore the interactive dashboard.
